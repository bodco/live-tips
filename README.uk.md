# Live Tips

**Тихий співпілот на твоїх дзвінках.** [English](README.md) · [Сайт](https://tower.bodco.pm/uk/live-tips/)

Live Tips слухає дзвінок на твоєму Маку і озивається лише тоді, коли потрібен факт або фраза:
питання до тебе, твоя черга, новий запит, дата, яку ти от-от пообіцяєш. Звук розпізнається на Маку
і нікуди не йде; у Claude йде лише текст. Після дзвінка підсумок, рішення і action items
потрапляють у Notion, а транскрипт лишається в папці проєкту.

Бета, яку один проєктний менеджер зробив для своїх дзвінків.

## Два способи запуску

| | Застосунок | Скіл |
|---|---|---|
| Що це | Нативний застосунок macOS у рядку меню | Скіл для Claude Cowork |
| Потрібно | Mac на Apple Silicon, macOS 14.4+, API-ключ Claude | Claude Cowork з підʼєднаним компʼютером, рекордер з цього репо |
| Підказки дає | Claude API, за подіями | Claude у твоєму чаті Cowork |
| Завантажити | [LiveTips.dmg](https://github.com/bodco/live-tips/releases/latest/download/LiveTips.dmg) | [live-tips.skill](https://github.com/bodco/live-tips/releases/latest/download/live-tips.skill) |

Обидва мають ті самі правила (`rules/`) і той самий рекордер, тож підказки поводяться однаково.

## Що робить

- **До дзвінка:** Prepare now пише бриф і картки фактів з папок проєкту і названих документів. Не обовʼязково: без неї дзвінок усе одно отримує підказки, коли звертаються до тебе, HELP NOW і відповіді на твої питання; запізніла підготовка підключається, щойно готова.
- **Під час дзвінка:** маленьке вікно з підказками з твоїх фактів, твій апдейт, коли твоя черга, готове речення на HELP NOW, транскрипт наживо, картина дзвінка (тема, що на тобі).
- **Дзвінки один за одним (Далі):** плануй і готуй наступні дзвінки, поки йде поточний, і переходь після одного питання: поточний коректно завершується, наступний стартує зі своєю підготовкою.
- **Будь-яка мова на вході, одна в транскрипті:** задай дзвінку одну мову, і кожного спікера записано нею (українська на англійському дзвінку виходить англійською).
- **Після дзвінка:** сторінка в Notion мовою дзвінка (підсумок, рішення, наші зобовʼязання, нові запити, відкриті питання, ризики, action items) з повним транскриптом як дочірньою сторінкою.

Порівняння з Fireflies, Fathom і Notion AI Meeting Notes: [tower.bodco.pm/uk/live-tips/compare](https://tower.bodco.pm/uk/live-tips/compare/).

## Репозиторій

| Шлях | Що |
|---|---|
| `app/` | Застосунок macOS (Swift) |
| `recorder/` | Рекордер: запис звуку, локальний Whisper, спікери, вікно підказок |
| `skill/` | Скіл Cowork: `SKILL.md`, `references/`, `settings.yaml` |
| `spikes/m0/` | Рушій підказок (Python) і тести |
| `rules/` | Спільні правила для застосунку і скіла |
| `notion-mirror/` | Необовʼязкова локальна копія сторінок Notion для фактів і пошуку |
| `keepalive/` | Необовʼязковий плагін Cowork, що тримає скіл на звʼязку під час дзвінка |
| `docs/` | Повний посібник: [English](docs/en/live-tips.md), [українською](docs/uk/live-tips.md) |
| `DEVELOPMENT.md` | Структура, збірка і виміри, на яких тримається дизайн |

Live Tips працює сам. З [PM Control Tower](https://github.com/bodco/pm-control-tower) він ще читає конфіги проєктів (люди, сторінки Notion, поточний стан).

Історія: Live Tips виріс усередині PM Control Tower; релізи до 0.5.8 [там](https://github.com/bodco/pm-control-tower/releases). Цей репозиторій зберігає ту історію.
