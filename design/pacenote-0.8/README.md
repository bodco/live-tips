# Pacenote 0.8: пакет для реалізації

Ребрендинг Live Tips → Pacenote (напрям лого A, «Route P») і редизайн 0.8 (вікно підказок Concept A, Home, форми, онбординг, панель menu bar, нові функції).

Лежить у `~/work/live-tips/design/pacenote-0.8/`. Почни з `COWORK-PROMPT.md`.

| Файл / папка | Що це |
|---|---|
| `COWORK-PROMPT.md` | промпт для Cowork: старт і фази F0-F6 |
| `REDESIGN-SPEC.md` | повна специфікація: принципи, кожен екран, бренд-шар, функції, фази, критерії приймання |
| `BRAND.md` | brand notes |
| `strings/` | таблиця рядків key / old EN / new EN / new UK (md + csv) |
| `brand/` | іконка, menu bar template, символ, вордмарк, lockup-и, favicon |
| `swift/` | `PacenoteTheme.swift` (токени, кнопки, бейдж), `MenuBarPanel.swift` (панель menu bar) |
| `tokens/` | `tokens.css` для веб-частини |
| `tips-window/` | робоче вікно підказок, відкривається в браузері |

Макети: полотно «Live Tips redesign» у Claude Design.
